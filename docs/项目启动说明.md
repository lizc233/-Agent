# 项目启动说明

## 已确定约束

- 场景：外卖配送、退款售后等客服领域；
- 平台：Windows 桌面；
- 运行方式：点击 EXE 启动，支持任务栏/系统托盘退出；
- 在线模型：DeepSeek API；
- 降级方式：API 不可用时使用本地检索和抽取式回答；
- 交互：文字问答、通知、自动弹窗；
- 暂不做：语音和真实订单操作；
- 视觉素材：等待用户提供美团袋鼠桌宠资源。

## 技术路线决定

主项目使用 Python，而不是 Java。理由是 RAG、Embedding、LangGraph、数据处理和 PyInstaller 在 Python 生态中衔接更直接，能够减少课程项目的工程风险。Java 可以作为后续桌面壳或对比方案，但不作为第一版核心实现。

第一版将 Agent 做成有限状态工作流，而不是开放式多 Agent 协作：问题分类 → 检索 → 证据校验 → 回答/澄清/拒答/转人工。这样更容易解释、评测和复现。

## 当前未确定项

- 袋鼠素材格式和授权范围；
- 客服知识库的具体条目；
- 是否使用本地 Embedding 模型；
- 是否需要安装包而不只是单文件 EXE。
