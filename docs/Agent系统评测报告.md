# 袋鼠可信客服 Agent 系统评测报告

## 评测范围

本次评测面向课程设计原型，不代表真实美团生产环境指标。固定评测集位于 `data/evaluation/customer_service_eval.json`，包含配送超时、餐损、疑似偷吃、退款、取消、越权请求、高风险投诉、知识库外问题和缺少订单号九类场景。评测使用本地规则、模拟订单工具和离线回答生成器，排除网络波动与 DeepSeek 话术差异，重点检查 Agent 决策和工具编排是否正确。对于数据库状态与用户实际情况冲突的场景，系统先询问确认；确认后只按本次事实处理，不修改订单表状态。

## 自动化验证

使用项目 `.venv` 执行 `python -m unittest discover -s tests -v`，共 53 项测试全部通过。测试覆盖登录密码、本人订单权限、语义检索、可信拒答、多订单按钮、Supervisor 并行、Skills 工具白名单、长期记忆用户隔离、Evidence Reviewer、工单状态机、PySide6 桌面行为，以及 MCP Streamable HTTP 初始化和工具发现。

MCP 测试使用官方 Python Client 与本地 Server 完成端到端连接，协商协议版本为 `2025-11-25`；同时检查所有 MCP Tool Schema，确认不存在 `user_id` 或 `current_user_id` 参数。

## 复现命令

```powershell
.\.venv\Scripts\python.exe -m scripts.evaluate_agent
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## 局限性

- 评测集规模较小，主要用于验证工作流和安全边界，不能等同于线上客服准确率。
- 订单工具使用模拟数据，数据库权限逻辑另由单元测试和实际 MySQL 联调验证。
- DeepSeek 在线回答具有网络和模型波动，本评测只验证其上游证据是否正确。
- 当前没有真实平台赔付、支付和物流接口，Agent 只能创建本项目售后工单，不能直接改变真实订单。
